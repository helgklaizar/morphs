# Руководство по установке и запуску (Setup)

В данном документе описаны предварительные требования, процесс установки зависимостей, настройка окружения и команды для запуска и тестирования системы Morphs Business OS.

---

## 1. Предварительные требования

Перед установкой убедитесь, что в вашей системе установлены следующие компоненты:
* **Python 3.11+** (рекомендуется Python 3.11.15 или 3.12)
* **Redis** (используется как P2P шина событий `EventBus` для координации агентов)
* **Git** (необходим для работы `GitMorph` и создания изолированных воркспексов через `worktree`)

---

## 2. Установка зависимостей

1. **Клонируйте репозиторий** и перейдите в корень проекта:
   ```bash
   git clone <repository_url>
   cd ai-saas-builder
   ```

2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. **Установите внешние зависимости**:
   В проекте используется файл зависимостей `ml_workers/requirements.txt`. Установите их с помощью `pip`:
   ```bash
   pip install -r ml_workers/requirements.txt
   ```

   *Примечание: Основные библиотеки включают `FastAPI`, `LanceDB` (векторное хранилище для RAG), `Kùzu` (граф AST кода), `mlx-lm` (инференс моделей на Apple Silicon), `msgspec` и `granian` (быстрый ASGI-сервер на Rust).*

---

## 3. Переменные окружения и конфигурация

Создайте файл `.env` в корневом каталоге проекта на основе следующего шаблона:

```env
# Токен API для интеграции с моделями Gemini (используется в gemini_agent.py)
GEMINI_API_KEY=your_gemini_api_key_here

# Порт для запуска FastAPI сервера Core Mind
CORE_MIND_PORT=8000

# URL для подключения к Redis (по умолчанию локальный инстанс)
REDIS_URL=redis://localhost:6379/0
```

Дополнительные конфигурационные файлы:
* `ml_workers/config.py` — загружает настройки из окружения с помощью `pydantic-settings`.
* `ml_workers/cost_limits.json` — устанавливает жесткие ограничения на токены для `CostHook` / `EconomyMorph`.

---

## 4. Команды запуска и тестирования

### Запуск сервера
Основной сервис запускается на FastAPI с использованием высокопроизводительного Rust ASGI-сервера **Granian**:
```bash
python ml_workers/main.py
```
Сервер будет доступен по адресу `http://localhost:8000` (или по порту, указанному в `.env`).

### Запуск тестов (Pytest)
В проекте реализована обширная база интеграционных и юнит-тестов в каталоге `ml_workers/tests/`.

Из-за архитектурных особенностей импорта модулей (смесь абсолютных импортов `core.*` и относительных путей), перед запуском тестов необходимо выполнить следующие шаги:

1. **Создайте символическую ссылку** `core` на папку `ml_workers` в корне проекта (это решит проблему с путями импорта `from core.xxx import yyy`):
   ```bash
   ln -s ml_workers core
   ```

2. **Запустите pytest** из корня проекта:
   ```bash
   pytest
   ```
   *Конфигурация pytest хранится в файле `pytest.ini` в корне проекта.*

## 5. Автоматическая проверка проекта
Для быстрой автоматической проверки настройки окружения, зависимостей, импортов, статуса Redis и прохождения тестов вы можете использовать скрипт:
```bash
./wiki/scripts/check-project.sh
```
Этот скрипт проверит окружение и автоматически настроит символическую ссылку `core -> ml_workers`, если она отсутствует.
