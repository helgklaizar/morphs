# Интеграции со сторонними сервисами (Integrations)

В данном документе описаны интеграции системы **Morphs Business OS** с внешними API, базами данных, протоколами и средами выполнения.

---

## 1. Google Gemini API (LLM Engine)

Система использует модели Google Gemini как основное "Ядро разума" (Core Mind) для генерации кода, логических рассуждений и дополнительной классификации рисков.

* **Используемые SDK**: `google-genai` (новое поколение библиотек от Google).
* **Модели**:
  * `gemini-2.0-flash` — быстрая модель с низкой задержкой, применяется для реалтайм-классификации в `YOLOClassifier` и быстрой проверки в `InjectionGuard`.
  * `gemini-2.5-pro` — мощная модель с большим окном контекста, используется для сложного рефакторинга кода, генерации структуры бэкенда (`APIMorph`) и локализации кодовой базы (`translate_codebase.py`).
* **Аутентификация**: Через переменную окружения `GEMINI_API_KEY`.
* **Резервный вариант (Fallback)**: В случае отсутствия ключа или недоступности сети система переключается на локальный MLX-инференс моделей на Apple Silicon (`mlx_agent.py`).

## 2. Redis (Шина событий EventBus)

Redis выполняет роль децентрализованного брокера сообщений для связи между специализированными морфами по протоколу Swarm.

* **Режим работы**: Publisher/Subscriber (Pub/Sub).
* **Ключевые топики (Topics)**:
  * `swarm.task.created` — создание новой задачи.
  * `swarm.epic.created` — создание эпика (задачи повышенной сложности с несколькими агентами).
  * `swarm.backend.generated` — готовность FastAPI бэкенда, триггер для генерации UI.
  * `swarm.ui.generated` — готовность React-интерфейса, триггер для тестов и авто-исправлений.
  * `swarm.deployment.failed` — ошибка на любом из шагов сборки, запуск процедуры отката изменений (rollback).
  * `mcp.telegram.notification` — отправка отчетов во внешние каналы связи.
* **Настройка**: URL подключения задается через `REDIS_URL` (по умолчанию `redis://localhost:6379/0`).

## 3. Model Context Protocol (MCP)

**Model Context Protocol (MCP)** — открытый стандарт обмена данными между LLM-агентами и внешними инструментами. Вместо написания уникальных драйверов под каждую систему, Morphs OS использует универсальный хаб `MCPRouter`.

* **Реализация**: `ml_workers/mcp_hub.py`.
* **Транспортный слой**: Стандартный ввод-вывод (`stdin`/`stdout`) с сериализацией сообщений в формате JSON-RPC 2.0.
* **Автоматическое обнаружение**: `PluginsManager` сканирует каталог `plugins/` на наличие файлов конфигурации `plugin.json` (или `*.json`), считывает команды запуска серверов и автоматически инжектирует их в `MCPRouter`.
* **Пример конфигурации (`plugin.json`)**:
  ```json
  {
    "name": "telegram",
    "command": ["npx", "-y", "@modelcontextprotocol/server-telegram"],
    "env": {
      "TELEGRAM_BOT_TOKEN": "your-token-here"
    }
  }
  ```

## 4. Telegram API (Уведомления)

Оповещение администраторов и пользователей о завершении сборки или критических сбоях происходит через Telegram-бота.

* **Логика отправки**: `SyncDaemon` отправляет сообщения, публикуя их в топик `mcp.telegram.notification`.
* **Механизм интеграции**: Под капотом событие обрабатывается через MCP-сервер Telegram, отправляя сообщение по сохраненному в профиле `telegram_chat_id`.

## 5. Системы хранения данных (Databases)

Система реализует гибридную архитектуру памяти, состоящую из трех независимых СУБД:

1. **SQLite (`morphs_system.db`)**:
   * Назначение: Реляционное хранилище для метаданных системы, профилей B2B-клиентов и журналов событий.
   * Коннектор: Стандартная библиотека `sqlite3` в Python.
2. **LanceDB (`.lancedb/`)**:
   * Назначение: Векторное хранилище исходного кода для реализации Code RAG (получение контекста файлов при генерации).
   * Эмбеддинги: 384-мерные векторы, сгенерированные локально с помощью легковесных sentence-transformers моделей.
3. **Kùzu Graph DB (`.kuzu_graph/`)**:
   * Назначение: Встраиваемая графовая база данных для отслеживания связей и зависимостей AST (файлы, классы, функции).
   * Визуализация: REST API дашборда транслирует структуру графа в формат D3.js Force-Directed Graph для рендеринга на веб-интерфейсе.
