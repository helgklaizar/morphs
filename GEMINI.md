# AI Projects Hub — оперативная память экосистемы

## Стек
- Rust / Tauri (TeleFeed, Antigravity)
- Next.js / TypeScript / React (TrendsMap Frontend, GitHub-Store)
- Python / SQLite (TrendsMap Backend, Turboquant)

## Архитектура (Проекты)
Проекты разделены на три зоны: `PROD` (стабильные), `WORK` (активная стройка) и `MVP` (эксперименты).
Эта папка (`MVP/morphs`) является хабом для экспериментальных ИИ-пайплайнов, скриптов на Python (LanceDB/SQLite) и прототипов (turboquant_mlx, local-ai-lab).
Для основных бизнес-приложений смотрите директории `PROD` (AI-Ecosystem, borsch-shop, tele-feed) и `WORK` (Borsch-core, mac-miner, simple-browser).

## Ключевые решения
- Мы являемся частью продвинутой среды разработки агентов от Google Deepmind.
- Каждая папка проекта содержит собственный `GEMINI.md` (живую память), который нужно читать при старте для моментального погружения. В этом же хабовом `GEMINI.md` мы будем хранить общие полезные материалы для всех проектов.
- **Стандарты экосистемы (Блоггинг, Память)** вынесены в `.gemini/rules/ecosystem.md`.
